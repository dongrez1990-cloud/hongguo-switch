# 第 72 轮：日志改成跨会话追加 —— 让崩溃不再吃掉证据（build72）

这一轮只改一件事，但它决定了**以后每一次排障能不能有证据**。

---

## 一、问题：**每次启动都把上一次的日志洗掉**

```cpp
std::FILE* f = openAt(CANDIDATES[i], "w");   // ← "w" = 截断
```

**实测后果**（就是上一轮发生的事）：`build69` 启动即崩，日志停在 `UI scale:` 那一行 ——
而**上一次运行**（很可能含控制条那几行）**已经被这次启动清空了** ✓。
本项目**唯一**能看见主机的窗口就是这个文件，而"崩一次就把前一次的证据抹掉"是它最坏的脾气。

## 二、修法：追加 + 会话分隔 + 超限轮转

| 行为 | 做法 |
|---|---|
| 跨会话保留 | 用 `"a"` 打开 ✓（每次启动写一行 `=== NEW SESSION … built <date> <time> ===` 分隔） |
| 不会无限增长 | 超过 **512 KiB** 先**轮转**（重开新文件，并在首行写明"上一次已被丢弃"） |
| BOM | 只在**空文件**时写一个（原代码写了**两个** BOM ✗；而且往文件中间追加 BOM 会破坏上一次的最后一行） |
| 读的人知道去哪找 | 头部那句说明改成：**SEVERAL SESSIONS, and the newest is at the END -- a crash cannot wipe the session before it** |

**好处立刻兑现**：你下一次运行（`build72`）之后，日志里会**同时**有
① `build69` 那次启动崩溃的尾巴（历史证据 ✓）与 ② 新会话的完整过程 ✓ ——
如果你这次再遇到崩，**崩溃前发生了什么都会留着** ✓。
