## 一、C11：提示栏开关 —— **即时生效，不是"需要重启"**

上一轮（`build56`）把提示条接上了，这一轮给它一个设置行：界面设置里 **Button hints = yes/no**。

**它是唯一一个我拒绝标"需要重启"的行**，因为那句话在这一行上**不准确**：提示条属于"每次打开都会重建"的界面，
所以诚实的做法是立刻生效。做法是给提示条套一个 20 行的容器，**每帧重读一次那个键**：

```cpp
void HintBarBox::draw(...) {
    const bool want = !hg::cfgIs("app.hints", "no");
    if (this->hints && want != this->shown) { ...setVisibility...; log; }
    brls::Box::draw(...);
}
```

代价是**一次带缓存的 cfg 读取 + 一次可见性比较**（hg_cfg 只在文件变化时重读），换来的是
**这个开关可以被使用它的人当场验证**，而不是靠下一次启动。

## 二、C14：电视风格播放器 —— 大部分已经在 A1/A2 里了，这一轮补上"在播什么"

"电视风格播放器"在参考版式里就是**下面那条控制条 + 上面显示在播什么**。前者在 `build43`–`build46`
（呼出/隐藏、播放暂停、进度与时钟、音量/倍速/缩放/清晰度、设置面板）已经做完了，所以 C14 真正缺的是
**标题**：

- 控制条面板的**顶行左侧**现在显示 **"剧名 ＋ 第 N 集"**；
- 这一行由**活动**交进来（`setOverlayTitle`），因为只有它知道剧名与集号；视图只负责画；
- **换集时同步更新**（`startEpisode` 里也调一次），否则自动下一集后标题会留在上一集；
- 空字符串就**什么都不画**，而不是留一条空条。
