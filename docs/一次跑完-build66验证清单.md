# 一次跑完：`build66` 的真机验证清单（约 10 分钟）

**为什么要这一页**：`build40`–`build66` 这一大批改动**都还没被真机跑过**（主机日志显示最后一次运行是 `build39`）。
每轮文档里各有一节"请真机确认"，散在 27 份文档里 —— 这一页把它们**按一次运行的顺序**合并起来，
从上到下走一遍就能同时验证全部内容。**只列"要看的现象"，不重复设计理由。**

当前部署：`/switch/hongguo.nro`（`build66`，SHA-256 `DA71BD7884B08445…`），`/switch/hongguo-build66.nsp` 带桌面图标。

---

## A. 启动与主页（约 2 分钟）

| # | 做什么 | 应看到 |
|---|---|---|
| A1 | 启动应用 | 主页顶部**没有**"32 cards in 4 sections"那一行；**横排栏就在顶部**（主页 收藏 历史 … 搜索 设置） |
| A2 | 看横排栏"主页"下面 | 小字显示**条数**（`显示 N 条`）；**收藏/历史**也是计数，**不再是"还没做好"** |
| A3 | 看每栏第 8 格 | 是 **一个环 + 双箭头 + "更多"**，不是空白灰块（`build58`） |
| A4 | 按 **X** | 网格在小/大两档之间切换，环在两档下都是**圆的** |
| A5 | 按 **LB** | 刷新（日志 `HOME: LB pressed -> refresh`），列表重建后**方向键仍然可用** |
| A6 | 按 **Y** | 进**搜索页**（不再是设置） |
| A7 | 按方向键上下 | **一次一格**，跳过标题行，**不弹回第一行**（这是 `build32` 的回归检查） |

## B. 底部提示条（约 1 分钟）

| # | 做什么 | 应看到 |
|---|---|---|
| B1 | 看任何界面底部 | 一排按键提示（`Ⓐ 打开`、`Ⓑ 返回`…），**焦点移动时内容跟着变** |
| B2 | 设置 → 界面设置 → **Button hints = no** | 提示条**立刻消失**（不用重启，日志 `the settings row turned the hint bar off`）；改回 yes 立刻回来 |

## C. 搜索与分类（约 2 分钟）

| # | 做什么 | 应看到 |
|---|---|---|
| C1 | 搜索页输 `AI` 或 `短剧` | 键盘是**主机的系统键盘**（可切拼音）；结果为**海报网格** |
| C2 | 看状态栏 | `显示 N 条（上游 10 条 + 本站 K 条）（共 199 条）` —— **明显多于 10 条** |
| C3 | 主页某一栏按"更多" | 进该分区**分类页**（24 部剧），**一直往下滚**：会继续加载（状态栏条数上涨） |
| C4 | 分类页滚到底 | 提示/日志 `CATEGORY: page N … (M loaded so far, 34 pages total)`；**已有封面不应重新下载** |

## D. 收藏 / 历史（约 1 分钟）

| # | 做什么 | 应看到 |
|---|---|---|
| D1 | 详情页按 **Y** | 通知"已加入收藏"，手柄**震一下**（若已开振动）；横排栏"收藏"点亮 |
| D2 | 横排栏 **收藏** / **历史** | 进界面：单个页面两个标签，卡片带封面/标题/进度/多久前 |
| D3 | **用手指点**另一个标签 | 列表切换后**方向键与 A 立刻可用**（`build65` 修的焦点悬空） |
| D4 | 在收藏页按 **X** | 真刷新（日志 `STORE: re-reading both files`） |
| D5 | 重启应用 | 收藏与历史**保持**（日志第一行有 `STORE: loaded …`） |

## E. 播放界面（约 3 分钟，重点）

| # | 做什么 | 应看到 |
|---|---|---|
| E1 | 按 **A** | 底部出现**控制条**：顶行左侧"剧名 第 N 集"，右侧五个方块（`100%` `1.0x` `1x` `720p` `设置`） |
| E2 | 按 **A** 再 | **暂停/播放**（第一下**不**暂停，这是用户要求的两步） |
| E3 | 上/下移动选中框 | 依次经过 播放 → 进度 → 音量 → 倍速 → 缩放 → 清晰度 → 设置 |
| E4 | 选中"1.0x"/"1x" 按左右 | 倍速/缩放变化（日志 `speed = 1.25x -> set rc=0, read back 1.25x`） |
| E5 | 选中"进度"按左右 | **拖动定位**（与以前完全一致） |
| E6 | 选中"720p"按 **A** | 打开画面菜单并**停在清晰度行** |
| E7 | 画面菜单里把**亮度**往右加几次 | **画面应变亮**（`build60` 的修复；日志 `PLAYERMENU: vf = 'eq=brightness=…'`） |
| E8 | 清晰度行左右移动 | **画面不重载**、行尾出现 `[A]`；按 **A** 才切换；按 **B** 不切换 |
| E9 | 选中"设置"按 A → 面板里按 **B** | **只关面板，不退播放**（`build64` 修的；日志 `B pressed while the settings panel is open -> it closes (not back)`） |
| E10 | 面板里改 **定时关闭 = 15 分钟** | 到点自动暂停并通知（日志 `sleep timer fired`）；改"固定显示进度条 = 开"后控制条隐藏时**底下仍有进度** |
| E11 | **ZL / ZR** | 上一集/下一集；**第一集按 ZL、最后一集按 ZR 应无反应**（有日志说明） |
| E12 | 设置面板 → **播放方式 = 自动下一集** | 让一集自然演完 → 自动进下一集，控制条标题跟着变 |
| E13 | 接电视播 1080p | 看日志 `PLAYER timing:` 那一行（我会自己取）→ 这一行直接说明卡在哪一段 |

## G. 如果某个 1080p 卡顿仍明显（可选对照，约 2 分钟）

每次改完**需重启**（表面在起播时分配）：

| 设置 | 期望 |
|---|---|
| `player.sw.height=0`（默认）+ `player.decode.fast=no` | 基准 |
| `player.sw.height=720` | 明显更流畅，画面略软 |
| 再加 `player.decode.fast=yes` | 更流畅、更糊 |

**把结论告我**（或让我取日志）：我会据此定默认值，或继续做"减少上传"那一层。
