## 这一版能做什么

主页 / 搜索 / 分类 / 详情 / 选集 / 播放全链路；选集页 **L/R 切换 20 集一组**、进场**自动定位上次看到的那集**；
播放中**插底座立即全屏**、**不自动休眠**；清晰度菜单只列出真的能用的档；主页右上角有**播放链路自检**状态灯。

## 必须知道的限制（**服务端行为，不是缺陷**）

1. **每条剧只开放前若干集**，且**因剧而异**（实测 5 部剧：50 / 12 / 11 / 13 / 6 集）。边界之后服务端稳定拒绝，
   官方网页对这些集显示锁图标并引导使用官方 App 解锁。**本项目不绕过任何访问控制** —— 界面会如实提示
   "该集需要授权/解锁"。
2. **清晰度上限 720p**。1080p/2k/4k 会被服务端拒绝。旧接口曾提供 1080p，已随接口退役。
3. **接口随时可能变化**（历史已发生两次）。接口变化后请先看 `docs/播放接口-*.md` 再判断是不是程序坏了。
4. 偶发的 403 属正常，**重试通常成功** —— 这也是 v1.0.0 保留完整重试预算的原因。
