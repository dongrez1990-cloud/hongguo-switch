## 一、C9 主题：**运行时就能切**，所以这一行不需要重启

先查了 borealis 的 Switch 后端，两个事实决定了实现方式：

```
switch_platform.cpp:73-83   启动时 setsysGetColorSetId() -> DARK/LIGHT（主机设置里的"基本黑/基本白"）
switch_platform.cpp:293-299 setThemeVariant() 会重新录制 deko3d 的静态命令列表
```

第二条是关键：**运行时切换是被支持的**（否则改主题就得重启）。所以：

- 设置行 **Theme = auto / dark / light**，标 `restart = false`；
- **auto** = 什么都不做，把决定权交回平台（它启动时已经问过主机）——这就是 borealis 的默认行为，
  本 App 不需要再实现一遍；
- 在设置里改完**立刻生效**，并把**结果读回来记日志**：

```
SETTINGS: theme='dark' applied; the platform now reports dark
boot: theme='auto' -> the platform reports dark (auto = whatever the console is set to) [build54]
```

**为什么"读回来"而不是只记请求**：主题没生效和没被请求，在只记请求的日志里长得一模一样 ——
这是本项目反复写下的同一条规矩。
