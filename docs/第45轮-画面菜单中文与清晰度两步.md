# 第 45 轮：画面菜单中文 + 清晰度两步选择（build45）

**B2（§3.2）** 与 **B1（§3.1）**，两件都在 X 画面菜单里，一起做（改的是同一个面板）。

---

## 一、B2：菜单说中文 —— 缺的**不是字符串，是接线**

交接文档写的是"中文键已在语言表……只差接线"，这一轮打开代码发现**比这还好**：

```
hg_lang.h 里早就有：  HG_T_PICTURE / HG_T_ROW_BRIGHTNESS..RESET（9 行） / HG_T_MENU_HINT
                      HG_T_VALUE_ON / _OFF / _AUTO / _CROP / _STRETCH / HG_T_NOT_AVAILABLE
面板实际画的：        hg_pmenu_row_label(i)        <- C 模型里的英文表 ROW_LABELS[]
                      hg_pmenu_row_value(&m, i,..) <- C 模型里的英文串（"On"/"Crop"/"(not available)"）
```

**所以真正缺的是 `hg_pmenu` 到语言表的那根线**。这一轮加的是 **键查询 API**，而不是新字符串：

```c
int hg_pmenu_row_label_key(int row);              /* 行标题 -> HG_T_ROW_* */
int hg_pmenu_row_value_key(const HgPMenu*, int row); /* 值若是词 -> HG_T_VALUE_*，数字/复合串返回 -1 */
```

只有**一个**新键必要：`HG_T_MENU_APPLY`（清晰度"待应用"标记，见下）。

**为什么两套文字都留着**：C 模型的英文串继续进 `hongguo.log`（这个项目的日志一律英文，搜起来一致），
语言键是**面板画的**。同一件事的两个用途，映射只有一张表，并且**有测试盯着**（新增 29 项：
每一行都必须有一个能解析出非空串的键）。

**提示行也改了**：原来只说"B 或 A 关闭 - 上下选行 - 左右调整"，而清晰度行现在**A 是生效**，
所以新提示是「… - 清晰度行按 A 生效」。一个只说"按 A 关闭"的提示，会让人以为光标停的那档正在播。

## 二、B1：清晰度两步选择（左右只移光标、A 才生效）

**原来**：`menu.qualityIndex` 一变就换清晰度（还有一条"和上次发出的索引比"的去重线）——
于是**每一次左右都重载一次流**。

**现在**：模型里多了一个数，两个数各司其职：

| 字段 | 含义 |
|---|---|
| `qualityIndex` | **光标**：左右随便移，谁都不碰播放 |
| `qualityApplied` | **正在播的那一档**（由播放器维护） |

- **A** = 生效：光标 ≠ 正在播时才发一次切换（日志 `QUALITY: A on the quality row -> APPLY tier …`），
  然后关菜单。若本来就相等，只记一行"nothing to do"。
- **B** = **取消**：光标弹回正在播的那一档再关。关掉的菜单若还留着没人应用过的档位，就是在骗人。
- **面板会把"待应用"画出来**：`540p  [A]`，行尾提示写明按 A 生效。这是两步选择**可见的那一半** —— 没有它，
  用户会以为光标停的档已经在播了。
- 旧的"光标一动就换档"整段删除，并在原处留了注释说明它去哪了、以及为什么删掉它不会
  （重新）引入 build33 修过的"每集开头跳回 0 秒"：那条路径（ladder 到达时自己起播第一档）还在，
  它由 build33 的 `lastQualityIndex` 负责。

## 三、验证

| 项 | 结果 |
|---|---|
| 主机测试 | **17 套 / 1162 项 / 0 失败**（pmenu 92 → 121，新增语言键与待应用标记的检查） |
| 构建 | 零警告（`out/build45.log`） |
| 部署读回 | `/switch/hongguo.nro` **SHA-256 与本地一致**（`3FCB417B79436F63…`），27,121,688 字节 |
| 主机产物 | `hongguo.nro` / `hongguo-build45.nro` / `hongguo-build45.nsp`（`build44` 已删除） |

**过程中被测试抓到的一件事**（写下来因为它正是测试的用处）：`hg_lang.h` 的**枚举**与 `hg_lang.c` 的
**表**必须逐项对齐，我在删掉重复键时只删了表里的 6 行、枚举里那 6 个键还在 —— 结果后面所有键**整体错位 6 位**，
lang 测试立刻报"key 119-124 没有英文/中文、key 41 的中文是 ASCII 的 English"。这类错位在界面上表现为
**菜单显示成完全不相关的文字**，而且只有那一条测试能抓到。

## 四、请真机确认

1. 播放中按 **X** → 菜单**全中文**：画面 / 亮度 / 对比度 / 饱和度 / 伽马 / 色相 / 清晰度 / 画面比例 /
   镜像 / 全部重置；值显示为 `+0`、`自动`、`关`、`720p` 等；底部提示「B 或 A 关闭 - 上下选行 - 左右调整 -
   清晰度行按 A 生效」。
2. 移到**清晰度**行 → 左右移动：**画面不应重载**（不跳回开头、不黑一下），行尾出现 `[A]`（例如 `540p  [A]`）。
3. 在清晰度行按 **A** → 这时才切换，并且菜单关闭；日志有
   `QUALITY: A on the quality row -> APPLY tier 3 (was 0, 5 tiers) [build45]`。
4. 再按 X → 移到清晰度行左右移动后按 **B** → **不切换**，下次打开菜单显示的还是正在播的那一档。
