# 电视（主机模式）播放画面不完整：根因与修复（build37）

**症状（用户报告）**：「前面接电视主机模式测试的时候，播放的画面电视显示不完整，只能显示其中的一部分，
掌机模式没问题」。

**根因**：软件渲染路径**把画面按"表面(swurface)的像素尺寸"铺进"视图的矩形"**，
而这两个尺寸在主机模式下**不相等**——于是只有左上角那一块被显示出来。

---

## 1. 数字（全部来自代码，不是推断）

### 1.1 主机模式下 borealis 内部发生的事

`switch_video.cpp:158-192`：分辨率变化时读实际显示分辨率，然后

```cpp
Application::onWindowResized(roundf(this->framebufferWidth), roundf(this->framebufferHeight));
```

`application.cpp:1183-1198` 延迟 100 ms 后调用 `setWindowSize`，而它（`application.cpp:1167-1181`）是：

```cpp
Application::windowWidth  = width;                                   // 主机模式 = 1920
Application::windowHeight = height;                                  //              1080
Application::windowScale   = (float)width / (float)ORIGINAL_WINDOW_WIDTH;   // 1920/1280 = 1.5
Application::contentWidth  = (float)ORIGINAL_WINDOW_WIDTH;                  // 1280  ← 逻辑宽度不变
Application::contentHeight = std::ceil((float)height / windowScale);        // ceil(1080/1.5) = 720
```

**关键**：逻辑布局**始终是 1280×720**（`contentWidth/Height`），`windowScale` 负责把它放大到 1920×1080。
所以视图的矩形在 draw() 里永远是 **1280×720**（逻辑）。

### 1.2 而软件表面是按"当时的窗口尺寸"分配的

`player_view.cpp` 里 `setupMpv` 分配 SW 表面：

```cpp
impl->swW = brls::Application::windowWidth;    // ← 主机模式下是 1920
impl->swH = brls::Application::windowHeight;   //                1080
```

日志里能看到这一行：`PLAYER setupMpv: SW surface 1280x720 stride=5120 …`（掌机模式下的值）。
**主机模式下启动播放器，这里就是 1920×1080**（表面对齐了原生分辨率，这本身是好事），
而它之后就再也不会变。

### 1.3 错配发生在这一句

```cpp
nvgRect(vg, x, y, width, height);                                   // 矩形 = 1280x720（逻辑）
nvgFillPaint(vg, nvgImagePattern(vg, x, y, (float)impl->swW, (float)impl->swH, 0, image, 1.0f));
                                                       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ 图案 = 1920x1080
```

`nvgImagePattern` 的宽高定义的是**图案（图片）铺开的范围**，而你要填充的矩形是 1280×720。
图案比矩形大 → **只画出了图案左上角 1280×720 那一块** → 画面"是完整的形状，但内容被裁掉了"
——正是用户描述的"只能显示其中的一部分"。

**为什么掌机模式没事**：掌机 1280×720，表面也是 1280×720，两个数字相等，正好对上。

---

## 2. 修法（一行，而且对能用的那种情形是恒等变换）

```cpp
nvgFillPaint(vg, nvgImagePattern(vg, x, y, width, height, 0, impl->swNvgImage, 1.0f));
```

图案范围改成**绘制矩形本身**：图片永远铺满它被画进去的那块区域，不管表面或窗口是多少。
掌机模式下 `width/height` 与 `swW/swH` 本来就是同一个数，所以**这一改对已经正常的情形没有任何影响**
——这正是它安全的原因。主机模式下：1920×1080 的表面被铺进 1280×720 的逻辑矩形，
再整体乘 `windowScale=1.5` 画到屏幕上，**最终仍是 1:1**，不糊也不裁。

## 3. 日志（下一版跑一次就能核对）

新增一行，**只在相关数字变化时打印**（所以插拔底座/切换模式时必定出现一次）：

```
SW surface vs view: surface=1920x1080 view=1280x720 window=1920x1080 scale=1.500 content=1280x720 [build37]
```

四个数字解释一切：表面（分配给 mpv 的像素）、视图矩形（逻辑）、窗口（borealis 报的实际分辨率）、
缩放（`windowScale`）。**掌机模式下应当是 `surface=1280x720 view=1280x720 window=1280x720 scale=1.000`**。
