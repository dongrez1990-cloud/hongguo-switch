# 第三方组件与许可（原本在"开源许可"栏目里）

**这份文件为什么存在**：应用里的 **"开源许可"与"关于更多"两个栏目已按用户要求删除** ✓。
但那份清单是**分发**时的法律要求（GPL/LGPL 通知），所以把它留在这里 ——
**删掉界面不等于可以丢掉通知**。

**恢复界面只需一行**：`makeLicenseGroup()` 与 `makeAboutGroup()` 都仍在 `settings_activity.cpp` 里
（带 `[[maybe_unused]]`，并写明理由 ✓），在 `createContentView` 里加回：

```cpp
tabs->addTab(hg_tr(HG_T_SETTINGS_LICENSE), []() { return makeLicenseGroup(); });
tabs->addTab(hg_tr(HG_T_SETTINGS_ABOUT),   []() { return makeAboutGroup(); });
```
