## 二、截图暴露的 bug：提示条把**未翻译的查找键**显示给了用户

```
+ hints/exit        B Back        A hints/ok
```

`Back` 是我们的字符串 ✓，而 **`hints/exit` / `hints/ok` 是 borealis 自己的 i18n 键，没被翻译** ✗✓。

**根因**：borealis 的 `AppletFrame` 用 `"hints/ok"_i18n` 注册动作，而 `_i18n` 走
`brls::i18n`，后者从 **`romfs:/i18n/<locale>/`** 读语言表（`lib/core/i18n.cpp:46-60`）——
**本 App 没有这些资源**，查不到就把**键原样返回** ✓。

**修法是改写而不是隐藏**：`Action::setHintText()` 是公开的（`actions.hpp:149`），
所以可以直接把动作的标签换掉 ✓。隐藏这两个提示更简单，但会**丢掉一条有用提示** ——
"按 A 打开你选中的东西"在设置页恰恰是用户需要知道的 ✓。

实现：**焦点变化时**（不是每帧 —— 每帧重建 Box 的孩子代价太大）沿焦点链走一遍，
把 `hints/ok` / `hints/back` / `hints/exit` / `hints/cancel` 换成语言表里的词 ✓；
**未知的键不改写但会点名**（`HINTS: leaving unknown key '…' alone`），
这样下次再出现裸键，日志里就有它的名字 ✓。为此补了三个语言键（确定 / 退出 / 取消 ✓）。

> 途中撞到一次真实的表对齐错误：我先加了**表格行**却漏了**枚举项** → `static const LangPair
> TABLE[HG_T_COUNT]` 立刻报 `index too large` ✓ —— 这正是这个语言表**必须同位置同时改**的地方（交接文档里记过一次同类事故）。补上枚举后一致 ✓。
