# 第 58 轮：「更多」卡片的配图（G3）（build58）

**要解决的问题**：那一格原来是一块**空的深灰矩形 + 两个字"更多"** —— 与"封面加载失败"的卡片长得**一模一样**，
而这是网格里最不能出现的一种样子。

---

## 一、选"画一个记号"而不是"模糊首图"

交接文档 G3 给了两条路：**用该分区首图放大模糊**，或 **nanovg 画箭头/加号**。选了后者，理由是成本：

- 模糊需要一次离屏渲染 + 一次模糊处理，而 **nanovg 没有模糊滤镜**；
- 两个箭头是四行路径，而且**在任何尺寸下都读得出来**（网格有大/小两档密度）。

**画的是环 + 双箭头**（`MoreMarkView`，nanovg 路径）：

- **环**按短边缩放（`min(w,h) * 0.26`），所以在大/小两档密度下都保持圆形而不是椭圆；
- **双箭头**用圆头描边画两条折线 —— "**这一格不再往列表里加东西，而是带你去这一栏的其余内容**"，
  `»` 正是所有界面表达"还有更多"的符号；
- 颜色取主题的强调色 ✓（跟随 C9 的主题切换 ✓）。

## 二、离线预览（因为真机之前看不到）

它最终只能在电视上看，所以我先用**同样的几何**在 Windows 上渲染了一张预览图核对构图
（环 + 双箭头居中、箭头不越出环）。这一步是廉价的，避免把一张明显难看的图送上去。

## 三、普通卡片一个像素都没变

`setMoreCard(true)` **只被 `buildRowView` 的"更多"分支调用**；其它卡片的标记是 `GONE`，
所以普通卡片与这一轮之前**完全一致**（这也是"改动能不碰的东西就不碰"的做法）。

## 五、请真机确认

1. 主页每一栏的最后一格（第 8 格）现在是 **一个环 + 两个箭头 + 下面的"更多"**，不再是一块空白灰。
2. 大小两档（按 X 切换）下环都是圆的。
3. 普通卡片看不出来有任何变化。
4. 主题切到 light（设置 → 界面设置 → Theme）后，环与箭头应跟着主题色变化。
