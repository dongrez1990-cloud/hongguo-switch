# 搜索网格 + 横排栏搜索入口 + "更多"接分类页（build39）

用户这一轮的四句话，逐条对应：

| 用户 | 做了什么 |
|---|---|
| 「搜索可以用了」 | 上一轮（build38）的系统键盘 + 搜索页 ✓ |
| 「搜索页显示在主页那横排上」/「搜索的按钮」 | **横排栏新增"搜索"按钮**（放大镜图标） |
| 「把搜索的结果图标按主页方式排列，可以往下刷」 | **搜索结果改用主页同一套海报网格** |
| 「不要只显示10个」 | **上游只给 10 条，且无法翻页 —— 实测 14 种参数全部无效**（见 §3），所以：结果按主页网格排布、可滚动，并把总数写在状态栏（"显示 10 条（共 201 条）"） |
| 「把主页的更多链接起来」 | **"更多"打开真正的分类页**（`/category/<slug>`，24 条），复用主页自己的网格与解析器 |

## 1. 横排栏多了"搜索"

侧边栏模型（`hg_sidebar.h/.c`）新增一项：

```c
HG_SB_ICON_SEARCH   /* 放大镜；nanovg 画一个环 + 四个方向的把手 */
items[3] = { HG_T_SEARCH, HG_SB_ICON_SEARCH, HG_SB_GROUP_PINNED, enabled = 1 }
```

- **放在 pinned 组**（"功能"组），理由与设置相同：搜索不是片库的一个分区，而是**作用于所有分区的工具**；
  排序是 `搜索` 在前、`设置` 在后，横排上就读成"内容 → 工具"。
- **永远可用**：它是唯一没有数据依赖的项（收藏/历史要有内容才亮）。
- 横排栏的 pinned 组因此从 1 项变成 2 项，主机测试跟着更新（**61 → 66 项**），
  包括一条新的边界检查："走遍 sections 环不会落到 pinned 组（下标 ≥ 3）"。

## 2. 搜索结果改成**主页同一套网格**（不是"照着做一遍"）

做法是把主页网格**暴露给别的界面**，而不是复制一份：

```cpp
// home_activity.hpp
brls::View* makePosterGrid(std::vector<HomeRow> rows,
                           std::function<void(const Series&)> onCard = nullptr);
void setPosterGridRows(brls::View* grid, std::vector<HomeRow> rows);
```

- `HomeGridView` 的点击行为从"直接 push 详情页"改成**一个可注入的回调**（`activate()`）：
  主页自己不设回调（保持原行为），搜索页/分类页各自设一个 ✓。
- 网格类本身仍在 `home_activity.cpp` 里（**不动主页的代码结构**），
  别的界面拿到的只是一个 `brls::View*` + 上面两个函数；`setPosterGridRows` 内部用
  `dynamic_cast` 兜住"传进来的不是网格"这种情况并记日志，不会野指针。

**因此"按主页方式排列"是构造上成立的**：列数来自 `hg_grid_layout`（有主机测试）、
上下移动来自 `hg_grid_row_step`（有主机测试）、跟随焦点用的是框架自己的钩子、
封面走的是带锁的图片加载器 —— 全是主页那一套，差别只在数据的行模型。

搜索页每次搜索就是 `setPosterGridRows(grid, rows)`（一行一张卡、无标题行），
所以**第二次搜索不可能残留第一次的卡片**（`setRows` 会重建并带 generation 守卫）。

## 3. 「不要只显示10个」——为什么做不到，以及实测证据

新写了探针 `app/src/tools/probe_search_paging.mjs`，把**14 种翻页写法**都试了一遍，
判据是**第一条结果的 id 有没有变**（不是条数 —— 一个被忽略的参数也会照常返回 10 条）：

| 尝试 | 结果 |
|---|---|
| `?page=2` / `?pageNo=2` / `?page_num=2` / `?p=2` / `?pn=2` | 200，**逐条与第一页相同** |
| `?offset=10` / `?start=10` / `?cursor=10` | 同上 |
| `?search_page=2` / `?tab_type=11&page=2` | 同上 |
| `/search/<kw>/2`、`/search/<kw>/page/2` | **404** |
| `?keyword=<kw>&page=2`、`?q=<kw>&page=2` | 200 但**一条结果都没有**（键名是 `search_page`） |

**结论**：上游 HTML 的搜索**只有第一页 10 条**，翻页本来由那个已死的签名接口负责（200 + 空 body）。
站点自己的搜索页现在也只能显示 10 条。所以 `totalCount`（"ai" 是 201）**必须显示出来**，
否则用户会以为搜到的东西就这十个 —— 状态栏现在写的是"显示 10 条（共 201 条）"。

> 如果你想真的能往下刷，唯一诚实的方向是**建一个本站索引再本地过滤**：分类页 **可以翻页**
> （`/category?page=2` … `?page=34` 是它自己的链接，实测有效），把若干页抓下来（每页 24 条）就能得到
> 几百条片库，搜索时在本地过滤。代价是首次建立索引要几秒钟、且它是**本站子集**而不是上游搜索的全部。
> 要不要做，等你定 —— 这一轮没有擅自加。

## 4. 「更多」接进分类页

### 4.1 分类页是什么（实测）

`app/src/tools/probe_category_page.mjs`：

```
GET /category           -> 200, loaderData = [category_layout, category_page]
                           category_page.recommendList[] = 24 条
                           字段：series_id / series_name / series_cover / tags / episode_right_text / vid_list
GET /category/comic     -> 200, 另一份列表（loaderData 键变成 category_$）
GET /category?tab_type=human|comic|ai  -> 与 /category 完全相同（参数被忽略）
GET /category/human、/category/ai      -> 404
分类页自己的链接里还有 /category?page=2 … ?page=34  -> 可以翻页
```

**关键**：分类页的条目字段与**首页卡片同名**，所以**不需要新解析器**。这一点在写任何界面之前
先用保存下来的真 router blob 验证过：

```
find_page: 1  key='category_page'
parse_home: rc=24 count=24
  [0] id=7686713195246930968 title=首辅娇娘 cover=...
```

### 4.2 分区 → 分类页的映射：**按 id 重合度实测**，不是按名字猜

`probe_tier_slug.mjs`（拿首页每个分区的 9 张卡与各 slug 的 24 条求交集）：

| 首页分区 | 分类页 | 重合 |
|---|---|---|
| human 热播真人剧 | `/category/real-drama` | **9 / 9** |
| comic 热播漫剧 | `/category/comic-drama` | **9 / 9** |
| ai 热播AI剧 | `/category/ai-drama` | **9 / 9** |
| all 热播短剧 | 没有对应页（它的 9 张里有 2 张也在 real-drama 里，是上游的跨类挑选） | —— |

两个反直觉的点，正是"按名字拼 URL"会错的地方：
`/category/comic` **存在但是另一份列表**（与任何分区 0 重合，是站点的"漫画"而非"漫剧"）；
`/category` 与 `/category/real-drama` **返回完全相同的 24 个 id**，所以 "all" 兜底用它。

这套映射写成 `Client::categorySlugForTier()`（一张表 + 上面的实测注释），
`HomeRow` 因此新增 `tabType`（首页分区自带 `tab_type`，随行传递）。

### 4.3 两个界面

- `Client::fetchCategory(slug, out)`：取页面 → router → **`hg_api_parse_home`**（复用）→ Series。
  slug 校验为 `[a-z-]+`，不合法直接拒绝（它会被拼进 URL）。
- `CategoryActivity`（新文件，~120 行）：标题 = 分区名，正文 = **同一个海报网格**，
  B 返回（`brls::sync` 推迟一帧），状态栏写条数。
- "更多"卡片的点击从"通知还没做好"改成 `push CategoryActivity(tier, slug)`。
