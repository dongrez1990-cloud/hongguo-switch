## 二、开源许可（C23）：这是许可证问题，不是装饰

`makeLicenseGroup()` 列出**这个二进制实际链接的东西**（对着 makefile 与 deps 核过，不是照习惯抄）：

| 组件 | 许可 | 为什么在这里 |
|---|---|---|
| hongguo-switch 本体 | **GPL-3.0-only** | |
| **borealis + wiliwili** | **GPL-3.0** | 界面框架，以及本 App 网格/播放器/平台代码所参照的 Switch 分支 |
| **libmpv (mpv)** | LGPL-2.1-or-later / GPL-2.0-or-later | 链接共享库、未作修改 |
| libnx | ISC | Switch 运行时：服务、线程、系统键盘 |
| deko3d / nanovg | MIT / zlib | 呈现帧的 GPU API；叠加层的 2D 绘制 |
| nlohmann/json | MIT | 只用于主机侧测试夹具 |

并且**专门写了"没有包含什么"**：不含上游品牌资产、不含字体（用主机系统字体）。
**分发 GPL 二进制而不给声明是许可证问题**，所以这一页有它的实用意义，不只是好看。

## 三、关于页：两行**过期的话**被修掉了

设置页上说假话比不说更糟。这一轮改掉两处（都是我这几轮改动造成的）：

| 原文 | 实情 |
|---|---|
| "Search: the endpoint answers 200 with 0 bytes; measured twice" | 签名接口确实死了，但**搜索界面早就不用它**：读站点自己的搜索页（`build38`）+ 本站索引（`build42`），**能用** |
| "A on the home header → refresh" | 那一行在 `build40` 被删掉，刷新改成了 **LB** |

同时**补上真实信息**（C20/C21）：**构建时间**（与日志头部同一个 `__DATE__/__TIME__`，
所以"我跑的是哪一版"在屏幕上也答得出来）、配置文件路径、**历史文件路径、收藏文件路径**。
按键表也补齐了这一轮新增的：Y(主页)=搜索、Y(详情)=收藏、LB=刷新、A/X/Y(播放)、**ZL/ZR=换集**。
