## 三、已经做好的地基（新会话不要重做）

1. **行模型在 C 层，且在主机上可测**：`hg_api_parse_home_sections()` + `hg_api_home_rows()`。

3. **`badge` 字段**：分集数（"全222集"），36/36 覆盖。
4. **封面加载器的请求令牌** `hg::ImageSlot`：格子复用时旧响应会被丢弃（日志 `IMG: DROPPED ...`）。

   取图前贴 1×1 占位纹理、超限（`HG_HTTP_ERR_TOO_BIG`）按实测最坏值重试一次。

## 五、环境约束与"不要重复发明"的仪器

### 约束

- **所有 `.ps1` 与 C/C++ 源文件必须纯 ASCII**（构建机是 GBK/936，非 ASCII 会糊）。
  改完用字节数核对：`($bytes | Where-Object { $_ -gt 127 }).Count` 应为 0。
  已知历史遗留的非 ASCII 字节在 `hg_crypto.c`/`hg_medusa.c`/`hg_router.h`/`hg_sign.*`/`hg_tables.h`——**没动**，
  其中 `hg_tables.h` 是生成文件、可能是真实数据，**不要盲改成 ASCII**。
- 工作区路径是非 ASCII（`<repo>`），**任何工具链的暂存目录都要在 `$env:TEMP` 下的 ASCII 路径**。
- **MSYS2 的二进制在这个沙箱里起不来**（`couldn't create signal pipe, Win32 error 5`）。
- `pwsh` 不在 PATH 上，用 `powershell`。
- **每个 pwsh 调用是独立进程**，`cd` 不保留——用绝对路径或 `workdir`。
- PowerShell 用 GBK 读 UTF-8 的中文文档会读糊 → **看中文文档用 read/grep 工具，不要用 `Get-Content`**。

### 已有仪器（不要重写）

| 工具 | 用途 |
|---|---|
| `sdmc:/switch/hongguo.cfg` + `hg_cfg` | **把实验变量变成 FTP 上一个文件**，改一行即可换臂，不用重编译。设置界面读写同一个文件 |
| `scripts/cover-probe.mjs` | 直连 CDN 探封面格式/尺寸（结论：JPEG+PNG 都能解；**尺寸后缀会 400**） |
| `scripts/router-shape.mjs` | 探首页 JSON 结构（就是靠它发现 4 个分区） |
| `scripts/nca-inspect.mjs` / `nca-identify.mjs` / `verify-nsp.ps1` | NSP 容器校验与 NCA 身份尝试 |
| `app/src/tests/dump_query.c` | 打印**真实签名搜索请求**（用它复测过端点仍死） |
| `hg_log` 的逐行 fsync 面包屑日志 | 每个关键步骤都有 `ENTER`/`OK`/`FAIL`，崩溃点看最后一行 |

### 这台机器上的教训（新会话最容易重犯的）

1. **判据的窗口必须覆盖你关心的那一刻。** 两次栽在这上面：SW 渲染的像素采样只取了前 5 帧，
   而那 5 帧在视频打开之前；配置读取只读 1 KiB，把设置本身截掉了。
2. **用一个样本当规律。** 封面缓冲上限按一张 76 KB 的样本定了 320 KiB，实测最大 1,091 KiB，
   于是一张卡没封面。
3. **"没反应"和"没收到"必须分开。** B 键曾完全无反应，为此加显式注册 + 日志；
   现在每个按键都打日志并回读结果。
4. **静态分析的结论要标出置信度。** 我曾断言"borealis 没有解码器"，实际 `setImageFromMem` 够了；
   也曾把"advanced=0 时 update 返回 0"当成异常证据，而 mpv 文档写明那是设计行为。
5. **改动一个"已经能用"的屏幕，必须带一条不用重编译的退路。**
