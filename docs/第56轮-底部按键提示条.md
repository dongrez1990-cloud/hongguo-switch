# 第 56 轮：底部按键提示条（E1）（build56）

**E1 的根因，交接文档写得是对的，但只对了一半**：`pushActivity` 只调 `setContentView()`，
所以每个界面的视图树里**没有一个收集提示的组件**。查了 borealis 之后发现：

```
brls::Hints              是一个现成组件（hint.cpp:56）
  构造时订阅 Application::getGlobalHintsUpdateEvent()  → 焦点一变就自己重刷（hint.cpp:131-137）
  refillHints(焦点视图)   从焦点视图沿父链收集已注册的手柄动作（hint.cpp:185-219）
  每个 Hint 画出主机的按键字形 + 该动作的标签（hint.cpp:63-64）
```

**所以 E1 缺的不是"要包 AppletFrame"，而是"没有任何界面把一个 Hints 放进去"** ——
这比交接文档的推测更简单，也让实现变成三行代码。

---

## 一、实现：一个包装助手，六个界面各一行

`hg_hints.hpp/.cpp`：`hg::withHintBar(content)` 返回一个 COLUMN 盒
`[content (grow=1)] [Hints (34 px)]`，并把它接进六个界面（主页 / 设置 / 搜索 / 收藏历史 / 分类 / 详情）。

**两个决定是我们自己的，写在头文件里**：

1. **放在底部**。borealis 自己的 `AppletFrame` 把提示放在**页眉**（`applet_frame.cpp:74-79`），
   而这个 App 跟随的参考版式把提示放在**底部**，电视机前的人也是在底部找它。
   `Hints` 组件两边是同一个。
2. **关掉只需一行 cfg**（`app.hints=no`）—— 与这个屏幕上其它版式改动一样的退路。

**播放界面故意不包**：它用 nanovg 画自己的控制条与叠加层（按键也是轮询而非注册），
全屏视频下面的提示条要么盖住画面要么把画面压小。这条写在头文件里，也记在清单 E1 备注里。

## 三、请真机确认

1. 主页底部应出现一排按键提示（`Ⓐ 打开`、`Ⓑ 返回`、`Ⓨ 搜索`、`LB 刷新` 之类），
   字形来自主机的按键字体。
2. **焦点移动时提示会跟着变**（例如焦点落到横排栏时出现"左右切换"、落到网格时"上下选行"）。
3. 进设置 / 搜索 / 收藏历史 / 分类 / 详情页，底部同样有一条；**播放页没有**（它有自己的控制条）。
4. 想关掉：`hongguo.cfg` 里 `app.hints=no`，重启后所有界面都不再有这一条（日志有
   `HINTS: app.hints=no -- no hint bar on this screen`）。

> 这一件同时解开了 **C11（界面设置·显示提示栏）**：现在提示条真的存在了，
> 那一行设置可以做成开关（下一轮接上，或直接给 `app.hints` 加一个设置行）。
