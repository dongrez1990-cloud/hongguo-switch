## 2. 每个问题的"做完的样子"（验收判据）

### #4 L/R 切分组
- **必须有日志**：`DETAIL: L/R -> group N of M (episodes 21..40) [build169a]`；
- 切组后**焦点落在新组的第一格**（不是停在旧位置），并且**滚动到可见**；
- **不能破坏**：B 键返回、分组切片与"完整列表"的双重语义（`detail_activity.cpp:187-198` 那段注释写得很清楚：
  格子标签用偏移、播放拿**完整列表**，否则"第 N 集"会错、自动连播会在组边界停下）；
- 边界：第 1 组按 L、最后一组按 R **不得越界崩溃**。

### #5 定位到最后看的一集
- **必须有日志**：`DETAIL: focus -> episode N (last watched, from history) [build169b]`；
- 没有历史时**行为不变**（焦点在第 1 集）；
- 历史那一集属于第 K 组时，**要先把组切到 K** 再定位（否则焦点落在不可见的格子上）；
- 与 #4 的组状态**不能互相打脸**（切组要更新"当前组"这个状态，两个功能共用它）。

### #2 底座全屏
- **必须有日志**：`APPLET: operation mode -> Console (docked) [build170]`（这条日志本身就是现在的盲区）；
- 播放中插/拔底座：**立刻**恢复正确的全屏画面，**不需要**退出重进；
- 掌机 → 主机 → 掌机 来回切都要对（不是单向修好）；
- 不能破坏 `player_view.cpp:3372-3417` 已有的"dock 时 windowWidth/Height 是 1920x1080，与画面矩形不一致"那套修正。

### #3 主机模式不睡
- 同一个钩子里**重新置位** `appletSetAutoSleepDisabled(true)`，并把 `rc` 打进日志；
- 判据：TV 模式播放中静置超过原来的休眠时间**不睡**；退出程序后**恢复**（不能把用户的系统设置改坏 →
  退出时仍然置回 `false`，那是 build159 已有的行为，不能回退）。

### #1 片源自动换新地址
- 触发点：① 自检六阶段里"stream"阶段失败；② 播放中 mpv 报流错误 / 长时间无画面；
- 动作：**重新调 `fetchPlayPlan`（新签名的 URL 就是"新地址"）并重新 loadfile**，只做**有限次**（建议 1 次，
  与 build151 的"一次透明重试"同样的精神），避免无限重启循环；
- **必须有日志**：`PLAYER: source failed (reason) -> re-fetching the plan and reloading [build171]`，
  以及成功/放弃两种结局各一行；
- **不得**与 `hg_client.cpp` 的九入口递归锁冲突（重取必须走 `Client::` 公开入口，不能在持锁时再进）。
