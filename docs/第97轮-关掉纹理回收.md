## 一、机制（我上一轮引入的回收逻辑）

```
格子刚离开绘制窗口  →  释放纹理（2.4 MB 还回去 ✓）
窗口跟着滚动往前     →  格子又回到窗口内  →  重新请求图片
图片要一秒多才到     →  这期间格子早已再次离开窗口  →  又被释放  ✗
→ 永远在"释放 ↔ 重取"之间抖动 → 你看到的"慢半拍" ✓
→ 而且这抖动本身就是一场**抓取风暴** → 滑动时崩溃 ✓
```

我上一轮想用"改成一屏外才回收"来缓解 ✓，但那个补丁**没真正生效** ✗（补丁报告里 `farAway` 是 0 处 ✓）——
