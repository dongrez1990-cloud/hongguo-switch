## 二、"关于更多"页有两句**现在不准确**的话（已修）

这两行是**用户用来判断"要不要重启"**的，所以不完整就是让人猜：

```
Restart needed for   : UI resolution, Home layout, Episode picker, Network, Diagnostics        <- 旧
Applied immediately  : Video decode (next video), player menu, seek style, quality row, refresh <- 旧
```

这一批新增的七个行（语言、限帧、显示 FPS、交换 A/B、低画质解码、解码缓存、软件表面）**都要重启**，
而 **Theme 与 Button hints 是即时生效的** —— 两行都没写。现在按代码实际行为分成两类：

```
Restart needed for   : UI resolution, Home layout, Episode picker, Network, Diagnostics, Language,
                       Frame limit, Show FPS, Swap A/B, Low-quality decode, Decode cache, Software surface
Applied immediately  : Theme, Button hints, Video decode (next video), player menu, seek style,
                       quality row, refresh
```

## 三、补上一行"控制条怎么用"

参考版式假设用户知道"呼出后怎么操作"，但这**猜不出来**，所以按键表新增一行：

```
In the player's control bar : UP/DOWN pick an item, LEFT/RIGHT change it (on PROGRESS: seek)
```

（顺带核对：整张按键表与现在的实际按键**一致** —— Y=搜索、Y=收藏、LB=刷新、A/X/Y 播放页三键、ZL/ZR 换集 ✓。）
