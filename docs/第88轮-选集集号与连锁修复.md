## 二、你这句话带出的连锁 bug（已修）

分组之后，网格拿到的是**切片**（第 2 组 = episodes 21..40 ✓），而原来的代码三处都在假定"我拿到的是整张表"：

| 位置 | 症状 |
|---|---|
| 格子编号 `setNumber(i + 1)` | **每组都从 1 开始** ✗ —— 你看到的就是这个 ✓ |
| `PlayerActivity(*series, *items, index + 1)` | 播放器**只拿到 20 集** ✗ → "第 N 集"显示错误 ✗，**自动下一集到组尾就停** ✗，ZL/ZR 也出不去 ✗ |
| 日志里的 `episode %u selected` | 同样按切片计数 ✗ |

**修法**：网格现在同时知道**两件事** —— 它画的那段切片 ✓ 和**整张表 + 切片在其中的偏移** ✓：

- 格子编号 = `偏移 + 切片内位置 + 1` ✓✓；
- 播放器拿到的是 **`*full`（整张表）+ 绝对集号** ✓✓ → 自动下一集可以跨组继续 ✓，集号也对了 ✓；
- 日志里的集号同样是绝对的 ✓。

> 换句话说：**如果只有你发现"格子数字不对"，我可能只改标签就交差了** ✗ ——
> 而顺着它查下去，才发现"播放器只拿到 20 集"这个更严重的问题 ✓。这是这一轮最值钱的收获 ✓。
