# 第 46 轮：控制条上的清晰度（A4）（build46）

**A4** 是 A 组最后一件"条上的方块"：控制条右侧现在有**四个**方块 —— 音量 / 倍速 / 缩放 / **清晰度**。

---

## 一、清晰度方块是"显示 + 一扇门"，不是第二个调档入口

- **显示**：文字来自播放器自己的 ladder，取的是 **`playingTierIndex`（正在播的那一档）**，
  不是菜单里那个光标。**控制条报告状态，菜单负责改变状态** —— 这条分界让两边永远不会各说各话。
  ladder 还没到（或那一档名字拿不到）时显示 `--`，而不是编一个名字。
- **操作**：`CONTROL_QUALITY` 上 **左右**不做任何事（换档会重载流，build45 定的两步规则是
  "光标随便移、A 才生效"），**按 A** → **打开画面菜单并停在清晰度行**，在那里用两步选择。

**为什么不在条上直接调档**：那会是同一个功能的第二个入口，而"每次按键都重载流"这个坑
（build45 刚填掉）就有第二个地方可以重新长出来。所以 A 在这里是**开门**，不是改值。

## 二、A 的语义变成"激活选中项"（控制条该有的语义）

| 选中项 | 按 A |
|---|---|
| 播放按钮 / 进度 | **播放 / 暂停**（原来的主操作，一字未改） |
| 清晰度 | 打开画面菜单（停在清晰度行） |
| 音量 / 倍速 / 缩放 | 不做事（它们是"值"，用左右调整，日志会写明为什么） |

控制条不在时按 A 仍然是"呼出控制条"（两步模型不变）。

## 三、顺手清掉的一个隐患：X 与方块各写一份"开菜单"

原来 X 键里有四行"打开菜单"的内联代码（置标志、bump revision、显示面板、让活动层让位）。
清晰度方块也要开菜单 —— 如果各写一份，**面板可见而标志为假**（或反过来）只是时间问题。
所以抽出 `openPictureMenu(row, haveRow)`，**X 和方块走同一条路**，并在里面用一行日志说明是谁开的：

```
PLAYERMENU: opened (row=5, by the control bar=1) [build46]
```

（`row=5` 就是清晰度行。）

1. 播放中按 A → 控制条右侧**四个**方块：`100%`、`1.0x`、`1x`、**`720p`（正在播的那一档）**。
2. 按**上/下**移到最右边的清晰度方块 → 按 **A** → 画面菜单打开并**停在清晰度行**，
   那里左右移光标、再按 A 生效（build45 的两步）。
