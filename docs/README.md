## 它能做什么（均已真机确认）

- 主页 / 搜索 / 分类（更多）/ 详情 / 选集 / 播放 全链路；
- 播放器：进度/音量/清晰度菜单、**L/R 滑条定位、ZL/ZR 上下集**、画面菜单（亮度/对比/饱和度/色调/伽马/比例/镜像）；
- 选集页：**L / R 切换 20 集一组**、**进场自动定位到上次观看的那一集**；
- 收藏、历史（一部剧一行）、历史行显示看到第几集；
- **播放中插底座立刻恢复全屏**（不需要退出重进）、**播放期间不自动休眠**；
- 主页右上角**播放链路自检**状态点（绿/红），设置页有六阶段明细；
- 缓存与可调项：HTTP 超时/代理/TLS、封面并发数、UI 缩放、主题、FPS 显示（`hongguo.cfg`，**cfg 已非必需**）。

## 它不能做什么（**都是服务端行为，不是程序缺陷**）

1. **每条剧只开放前若干集**。实测（2026-10-16）5 部剧的边界分别是
   **50 / 12 / 11 / 13 / 6 集，因剧而异**；边界之后服务端稳定返回
   `{"error":"protected_playback_unavailable"}`。官方网页对这些集显示锁图标，并引导"下载官方 App 免费解锁"。
   **本项目不绕过任何访问控制**：界面会如实提示"该集需要授权/解锁"，不会伪装成网络错误。
2. **清晰度上限 720p**（当前播放接口）。1080p / 2k / 4k 会被服务端拒绝（稳定拒绝，重试无用）。
   旧接口曾提供 1080p，但它已于 2026-10-16 被退役。
3. **接口随时可能变化**。项目历史里已经发生两次：一次接口整体退役（返回空壳），
   一次播放地址迁移到网页侧的 `play-info`。两次的实测过程与替代方案见
   `播放接口-2026-10-16-实测补充.md` 与 `新播放接口-第21轮.md`。
4. **偶发失败属正常**：同一请求服务端会间歇性返回 403，**重试通常成功**（这也是为什么重试预算是必要的，
   而不是"把第一次拒绝当定论"）。
