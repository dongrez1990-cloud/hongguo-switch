## ① 先补我引入的：退出时等待后台写线程（最要紧 ✓）

## ② 播放期间不再每秒写日志（顿挫的**源头** ✓✓）

日志里每秒至少三行 ✓：`MPV: PLAYING` ✓、`PLAYER timing …` ✓、`frame N` ✓ ——
每行都要 **open + append + fflush + fclose**（还定期 fsync ✓）→ 只要写卡，就会撞上 SD 卡内部整理（GC）✗✓ → 顿挫 ✗。

**做法**：加 cfg 开关 ✓ `log.playback=off`（**默认 off** ✓）：
- **播放期间**：这三行**不写** ✓（改为每 30 秒写一行汇总 ✓，或完全不写 ✓）；
- **需要排查时**：`log.playback=full` ✓ → 恢复逐秒 ✓；
- `MPV draw #N`（前 5 帧 ✓）与错误行**照旧写** ✓（它们不是周期性的 ✓）。

**预期**：顿挫**根除** ✓（不再有周期性写卡 ✓）。

## ③ 换集时清一次画面（"闪旧帧 → 黑屏" ✓）

现象：换集瞬间**闪现旧画面** ✗ → 随后**黑屏**（程序仍在跑 ✓）。
原因：deko3d 的 framebuffer 复用 ✓ —— 新流还没出帧时，FBO 里还是旧内容 ✗。

**做法**：`start()` 里（新 loadfile 之前 ✓）**清一次 FBO** ✓（用现成的 `recordStaticCommands` 路径 ✓，
本项目"灰色清屏"就是这么做的 ✓）；或**等新流第一帧到达再显示** ✓（更平滑 ✓，但要改呈现时序 ✗ → 先做"清一次" ✓）。
